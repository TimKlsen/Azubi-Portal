# Azubi-Portal
Dieses Portal können Auszubildende nutzen um ganz leicht und ohne viel Verwaltungsaufwand durch die Ausbildung zu kommen. Es können Dokumente gespeichert werden, es können Tagesnotizen gemacht werden und auch Ausbildungsnachweise generiert werden. Einen Überblick über die Landing Page ist in der README zu finden.
